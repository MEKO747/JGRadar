状态语义 · 四态与转移

一个状态不是标签，而是 position / observed_at / confidence / std 四个量的一组取值约定。

融合仲裁 · 优先级阶梯与两道闸

先问"这是哪一种证据"（classify），再问"它现在还准不准"（误差上界）。两道闸刻意分开：否决必须计数。

1 最高radio_fresh · 信息年龄 ≤ 0.2s
2vision_measured · 视觉看门狗 ≤ 0.5s
3radio_stale · 信息年龄 ≤ 10s
4vision_occlusion_hold · 卡尔曼外推
5 最低vision_blind · 航点盲猜

误差上界闸：实测态 = 信息年龄 × 500 cm/s；预测态 = 3σ × position_std_cm。 超过 500 cm 即 veto（计数）。500 / 500 = 1.0 秒保质期。
滞回：现任源保持；挑战者需连续 dwell 0.3s，跳变 ≥ 150cm 时抬到 reacquire 0.8s。

两个时钟 · 绝不能混

混用不会报错，只会让回放和实时的行为不一致。

captured_at → 推进滤波器（dt 必须是物理时间） now → 新鲜度 / 看门狗 / 帧龄 回放：now = 帧时间线（帧龄恒 0，可复现） 实时：now = time.monotonic() 帧龄 > 60s 或大幅为负 → ClockMismatch 直接抛
