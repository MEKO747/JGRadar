## 修复结果

| 原问题 | 当前行为 |
|---|---|
| 没有视觉新帧，融合与发布也停 | 实时源默认使用独立消费线程。视觉暂时无新包或包超龄时仍仲裁、发布；旧视觉会按看门狗失效 |
| 空共享缓冲区/信箱被替换 | 显式判断是否传入对象，启动后收到的无线电数据能进入同一个缓冲区；信箱容量配置已生效 |
| 身份改判生成第二辆车 | 在空间上继续关联原轨迹，身份差异作为软代价；新身份证据进入原票箱，旧编号退出时主动撤回 |
| 数字印证说明与权重不一致 | 保留原有“数字只能印证完整车类”的规则，删除反复矛盾数字能够独自翻盘的错误承诺；EGA 从颜色和数字组合完整身份后参与投票 |
| 盲区航点配上原地的小误差 | 误差包含航点/裁剪位置相对滤波中心的距离，以及计算后暂存时间的运动余量；远处猜测可能被拒绝发布 |
| 重捕获被一次漏检绕过 | 独立保存重捕获等待状态，未连续确认前不刷新最后已确认观测时间；中途漏检后重新累计 |
| 旧坐标被赋予更新的时间 | 原样保留真实观测时间，新增发布序号区分发布先后；来源切换不再让旧数据显得更年轻 |
| ROI 数量增加后 ONNX 装甲检测全空 | 模型接收独立且尺寸正确的 ROI，动态模型使用真正的 N 维批量输入；固定 batch 也按模型声明处理 |
| 视觉历史队列不断增长 | 待消费数据按编号只保留最新值，Stage B 及时消费；重置会清空历史和轨迹 |
| 卡顿后滤波器只预测 0.5 秒 | 分段积分完整的实际时间；零时间不引入虚假位移，重复/倒序观测包拒绝进入跟踪 |
| 无法投影的标定点仍让校验通过 | 非有限残差导致校验失败，质量统计不再把坏点静默删除 |
| 非零高度共面点求外参失败 | 在局部平面求解后转回场地坐标，覆盖地面、50 cm 高台和倾斜平面 |
| EGA 只有车框/装甲颜色，没有正式编号 | 增加 MobileNet 分类后端，按原训练方式预处理；同车颜色与数字组合为 B/R 身份，S→7，Q/灰色不生成身份 |

## 兼容性与后续实测

`observed_at` 表示实际观测时间，换来源后可以采用更旧的有效信息。需要判断结果先后时，使用 `publication_seq` 和 `published_at`。
`frame_seq` 仍指关联的视觉帧，所以视觉暂停期间多个发布结果可以引用同一帧；尚无视觉帧时为 -1。
预测误差需要同时考虑 `position_std_cm`、`prediction_offset_cm` 和预测计算后的等待时间，不能只看滤波标准差。

默认 EGA 检测配置已启用数字模型。检测预览能显示数字和颜色，但不运行持续跟踪、定位与融合；独立装甲的 `car_index=-1`，不会凭空声明所属车辆。
你自己的实拍内外参仍需现场标定，参考录像参数不能代替真实安装位置。

不占用相机的复核命令：

